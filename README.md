# ShipXY Dashboard - 全球船舶追踪3D可视化平台

基于船讯网 (ShipXY) API 开发的全球船舶实时追踪3D可视化平台。

## 功能特性

- 🌍 **3D地球可视化** - 基于Three.js的逼真3D地球，实时展示全球船舶位置
- 🔍 **船舶模糊搜索** - 支持船名/MMSI/IMO/呼号多维度搜索
- 📊 **实时仪表盘** - 船舶统计、类型分布图表、活跃船舶列表
- 🗺️ **航线规划** - 点到点/港到港航线可视化，ETA查询
- 🌊 **气象天气** - 点位气象、台风追踪、港口潮汐图表
- ⚓ **港口查询** - 港口信息、靠泊/锚泊/预抵船舶查询
- 📋 **船舶档案** - 详细船舶资料、注册信息、建造信息
- 🎨 **精美动画** - 脉冲标记、粒子航线、大气辉光效果

## 快速开始

1. 打开 [GitHub Pages 地址]
2. 点击右上角 ⚙️ 设置 API Key（可选，无Key使用演示模式）
3. 在 [船讯网控制台](https://api.shipxy.com/v3/console/overview) 获取 API Key

## API 模块

| 模块 | 功能 |
|------|------|
| 船舶查询 | 模糊搜索、单船/多船位置、周边/区域船舶、船籍、档案 |
| 港口查询 | 港口信息、靠泊船、锚泊船、预抵船舶 |
| 历史行为 | 历史轨迹、搭靠记录 |
| 挂靠记录 | 历史挂靠、指定港口、当前挂靠、港口历史船舶 |
| 航线规划 | 点到点/港到港航线、ETA查询 |
| 气象天气 | 点位气象、海区气象、台风、港口潮汐、全球气象 |
| 海图应用 | 船位光栅图、港口瓦片 |
| 海事数据 | 航行警告 |
| 监控推送 | 船队管理、实时船位、到离港、区域监控、ETA推送等 |

## 技术栈

- **Three.js** - 3D地球渲染
- **Chart.js** - 数据可视化图表
- **原生JavaScript** - 无框架依赖
- **船讯网API v3** - 船舶数据服务

## 本地开发

```bash
# 使用任意HTTP服务器
npx serve .
# 或
python -m http.server 8000
```

## 快捷键

| 按键 | 功能 |
|------|------|
| Ctrl+1 | 仪表盘 |
| Ctrl+2 | 船舶搜索 |
| Ctrl+3 | 航线规划 |
| Ctrl+4 | 气象天气 |
| Ctrl+5 | 港口查询 |
| Ctrl+K | 聚焦搜索框 |

## 注意事项

- API Key 仅存储在浏览器 localStorage，不会上传到服务器
- 无 API Key 时使用内置演示数据
- 推荐使用 Chrome/Edge 浏览器以获得最佳3D体验
